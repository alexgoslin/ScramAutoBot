Claude & models

Stored only in this browser's chrome.storage.local and sent only to api.anthropic.com.

Claude Fable 5.1 is the most capable (and most expensive: about 2.5× Opus 5.5 per token). Opus 5.5 is a good cheaper choice.

Autopilot

In both modes Autopilot never logs out, deletes or deactivates, pays or upgrades, or posts/sends/invites/reports — and never submits what it types.

Step files

How the build steps given to Scram's AI are written. Applies the next time you generate a handoff.

Steps over the size or checklist limit are split automatically into smaller steps when the handoff is generated. If Scram's AI still struggles with a step during the build, Autopilot hands it that step in two halves.

What it has learned about Scram's AI

When Scram's AI says it can't do something, Autopilot writes a lesson here and never asks for that again. It keeps these across runs. Delete any that are wrong, or add your own.

    Control Center connection

    The Control Center is the RoboBuild website (robobuild.builtonscram.com): you start runs, answer questions and read everything there, while this extension does the work in this Chrome. Your Anthropic API key never leaves this browser — only the run's progress, its log, the documents it writes and usage totals are sent.

    How to connect — takes about a minute
    1. 1
      Open the RoboBuild site and sign in

      Go to robobuild.builtonscram.com and sign in — or sign up if you're new. (Testing on Dev? Switch the Environment above to Dev; the button below then opens the Scram editor — press Run at the top to open the app.)

    2. 2
      Go to the Extension page

      Click Extension in the app's left menu, then press Connect extension. If this Chrome was connected before, press Reconnect (new token) instead.

    3. 3
      Press “Copy both”

      The app shows a Connection ID and a pairing token — only once. Copy both copies them together, like {"computer_id": 3, "token": "…"}.

    4. 4
      Paste it here
      It connects by itself as soon as you paste.
    5. ✓
      Check it worked

      This page turns green, and within a few seconds the Control Center's Extension page shows Connected ● with this extension's version. Start runs from New run in the Control Center; click the RoboBuild icon in Chrome's toolbar any time to see what it's doing.

    Troubleshooting
    • “That Connection ID and token don't match” — the token was mistyped, already replaced, or the connection was revoked. In the Control Center press Reconnect (new token), then Copy both and paste again.
    • “Couldn't reach the Control Center” — check you're online. If the app was published to a new address, update the Base URL under Advanced below.
    • The Control Center says “Offline” — Chrome must be open with this extension on. It checks in every few seconds while a run is going and about every 30 seconds otherwise; opening this page or the toolbar popup checks in straight away.
    • Lost the token? It's only shown once, on purpose. Make a new one with Reconnect (new token) — the old one stops working.
    • Disconnect forgets the token here; your runs and files stay. Revoke the connection in the Control Center too if you're done with this Chrome.

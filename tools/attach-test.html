2. Run the test

The extension makes a small file called scram-upload-test-….md in memory (nothing is saved to your computer) and puts it into Scram's chat box — first straight into the chat's hidden file input (the same way Claude in Chrome did it), then, only if needed, by drag-and-drop, paste, or a real click on the paperclip. It stops as soon as the file shows up. The last two methods use Chrome's debugger, so you may briefly see a “debugging this browser” bar. Watch the Scram tab while it runs.
